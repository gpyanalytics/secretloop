# Benchmark repository identities and pinned commits
#
# Written for 0.1.4 because the 0.1.4 precision slice could not reproduce the
# 20-repository benchmark: the clones were deleted after measurement, as the
# study's own safety rules required, and nothing recorded which commit each
# was at. This file exists so the identities that ARE on record stop depending
# on someone reading prose to find them.
#
# STRICTLY RECOVERED, NEVER INFERRED. Every line below is copied from a file
# in this repository or its git history. Nothing was cloned, resolved against
# a remote, guessed from a date, or reconstructed. Where a value is not on
# record it says "unknown" -- a wrong SHA in a file called repos.txt is worse
# than an absent one, because the next person would trust it.
#
# Sources:
#   docs/BENCHMARK.md      the 20-repository study, measured 30-31 Aug 2026
#   bench/MULTI-CORPUS.md  the 14-repository false-positive corpus
#   bench/COMMANDS.md      tool invocations, corpus A and corpus B
#   bench/BASELINE.md      recorded corpus A / corpus B baseline
